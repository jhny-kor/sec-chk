3. App purpose and target audience:
KODA is a local macOS security review tool for software developers, security reviewers, indie makers, and small teams preparing a release. It helps users find security issues in local source projects before shipping by scanning selected folders/files for secrets, dependency risk indicators, insecure configuration, risky code patterns, and missing security process guardrails. It provides actionable findings, risk scoring, and mapped guidance across common security standards so users can prioritize fixes and keep release evidence.

4. Setup and access instructions:
No account, login credentials, demo account, subscription, payment, or network setup is required. Open KODA, choose Folder Selection or File Upload, select a local project folder or file/archive, then click Run Security Scan. After the scan, open Overall Results or a standard-specific card to review findings and remediation guidance. A synthetic sample project was used for the recording: koda-demo-project / koda-demo-project.zip.

5. External services/tools/platforms:
The core app functionality runs locally on the Mac. It does not require authentication services, payment processors, data providers, AI services, or external platforms for the default scan flow. Optional advanced workflows may generate instructions for external security tools such as OSV or OWASP ZAP only when a user explicitly chooses to use those workflows; they are not required for core functionality.
