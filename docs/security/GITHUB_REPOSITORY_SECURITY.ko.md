# GitHub 저장소 보안 체크리스트

다음 저장소 설정은 로컬 파일만으로 완전한 검증이 어렵기 때문에 GitHub에서
직접 확인하고 증적을 남겨야 합니다.

- 기본 브랜치 보호
- Pull Request 및 승인 리뷰 강제
- Actions 최소 권한과 secret 보호
- Dependabot·secret scanning·code scanning 활성화
- 릴리스 서명과 provenance 보관
