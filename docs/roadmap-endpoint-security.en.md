# KODA Endpoint Security Roadmap

This document is the English view of the endpoint posture roadmap. The supported
command today is `host-scan`; the roadmap records design history and planned
evidence rather than promising every listed item.

KODA keeps endpoint checks read-only and local by default. Validate current
installation and operation details in the [English CLI guide](usage.md) and the
[English Linux guide](install/linux.md).
