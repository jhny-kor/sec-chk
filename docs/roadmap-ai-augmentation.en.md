# KODA AI Augmentation and CI/CD Roadmap

This roadmap records the English view of the AI triage, reachability, deterministic
auto-fix, and changed-file CI work. KODA keeps the default path offline-first,
read-only, and privacy-preserving; every network or write-capable feature is
opt-in. The Korean planning document contains the full decision history and
implementation notes.

Current implemented areas include local/cloud LLM provider boundaries, AI triage
that cannot change severity, import-based reachability labels, deterministic
dry-run auto-fix, and changed-file CI scope. Use the [English CLI guide](usage.md)
for current commands rather than treating roadmap checkboxes as support promises.
